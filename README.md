# Yame Editor

An unofficial in-game editor for **Football Manager 27**: a control panel (F6), AI conversations with your players, and a smartphone to text your staff, your players, your best friends at other clubs and even your rival's manager.

Website: https://yame-editor.pages.dev/?from=github  
Video: https://youtu.be/lmt9gOd54WI

## Download

Get the latest zip from **Releases** (right side of this page). Check that its SHA-256 matches the value in the release notes.

## Install

| Step | What to do |
|---|---|
| 1 | Close the game. |
| 2 | Unzip the file and run `Install.bat` (if Windows asks, choose Run). It finds the game, installs BepInEx when needed and backs up what it replaces. |
| 3 | Start the game. The first start after installing takes a few minutes. |
| 4 | Load a save and press **F6**. |

To remove it, run `Uninstall.bat`.

## Languages

Korean, English, Simplified Chinese, French and German (the editor follows the game's language).
